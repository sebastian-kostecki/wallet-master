# Term deposits (lokaty) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add term deposits as a third `/konta` tab: one-legged capital on bank accounts (excluded from P&L), optional interest income linked to the deposit, manual create/close plus assign from existing transactions.

**Architecture:** New Variant A domain `Deposits` (`deposits`, `deposit_movements`). Index chrome stays `accounts.index?kind=deposits`; writes use `/lokaty` routes. Shared `BudgetExclusion` extends today’s `transfer_id IS NULL` rule so open/close-principal legs are also out of budget, summary, dashboard cashflow, and the transfer matcher. Interest is a normal income row with `kind=interest`.

**Tech Stack:** Laravel 13, PHP 8.5, Inertia Vue 3, Ziggy, vue-i18n, Vitest, Pest 4, Tailwind v3, Sail.

**Spec:** `.docs/superpowers/specs/2026-08-27-deposits-design.md`  
**Do not use:** `.docs/superpowers/specs/2026-06-11-deposits-design.md` or `.docs/superpowers/plans/2026-06-11-deposits.md` (stale; CSV auto-classification is out of v1).  
**Suggested branch:** `feature/deposits`

## Global Constraints

- Variant A: `Actions/Deposits/`, `Http/{Controllers,Requests,Resources}/Deposits/`; no `app/Services/`; Actions never import `Http/Resources`.
- Domain folder name **Deposits** (plural). UI label PL **Lokaty**.
- Query `kind=deposits` on `accounts.index`. Missing/invalid `kind` still defaults to Rachunki.
- Open/close/assign only on active bank accounts (`bank !== cash`). Checking and savings allowed.
- Dates in FormRequests: `d-m-Y`. Amounts: `decimal:0,2`.
- Capital transactions: `category_id`, `transfer_id`, `pocket_id` all `null`. Interest: `category_id` required, `type=income`.
- One placement = one row; unique `(deposit_id, kind)` on movements; unique `transaction_id`.
- No CSV classifier, no delete, no principal edit, no partial close.
- Code/comments/commits in English. Copy in `pl.json` / `en.json`.
- After PHP: `vendor/bin/pint --dirty --format agent`, then `./vendor/bin/sail artisan test --compact` on the task’s test file(s). After Vue/TS: `npx prettier --write` on touched files; `npm test` for Vitest files.

```php
<?php

declare(strict_types=1);

namespace App\Support\Transactions;

use App\Enums\DepositMovementKind;
use App\Models\Transaction;
use Illuminate\Database\Eloquent\Builder;

final class BudgetExclusion
{
    /**
     * @param  Builder<Transaction>  $query
     */
    public static function apply(Builder $query): void
    {
        $query
            ->whereNull('transfer_id')
            ->whereDoesntHave('depositMovement', function (Builder $movement): void {
                $movement->whereIn('kind', [
                    DepositMovementKind::Open->value,
                    DepositMovementKind::ClosePrincipal->value,
                ]);
            });
    }
}
```

`BudgetTransactionQuery::excludeTransfers`: replace body with `BudgetExclusion::apply($query);` (keep method name for existing callers).
